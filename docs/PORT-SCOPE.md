# 迁移范围

用户于 2026-10-09 明确选择：**“就要字体和像素画两个”**。

| 原版能力 | 当前移植方式 |
|---|---|
| Photo Importer：本地图片、URL、缩放、透明度、颜色精度 | 图片转换标签页；输出现代 LT 蓝图 |
| Typewriter：字体选择、字号、颜色、字体样式、旋转 | 字体转换标签页；支持系统字体和 TTF/OTF，输出现代 LT 蓝图 |
| 原版打印机／打字机预制结构及旧 Forge GUI | 以客户端工具界面替代，F9 或 `/alet` 打开 |
| 原版直接打印方块或物品纹理 | 本次不提供游戏对象纹理采集；可将所需纹理作为图片导入 |
| 动画 GIF／逐帧播放 | 仅支持第一帧静态像素画 |
| 卷尺、纹理方块、绳索、音乐、信号、可编程结构 | 不在用户选定范围内 |
| 旧版 ALET 结构／存档升级 | 不提供；使用新版 LT 原生蓝图格式 |

图片和文字保持真实 ARGB 颜色，一像素一小格，可合并为同色相邻矩形。
LT 蓝图使用当前的 `t/grid/min/size/tiles/boxes/trans` 格式，经真实客户端验证其读取与数据组件往返。
